Cohort SOS

A real-time rescue network for builders: launch an SOS when blocked, get help in a rescue room, reward the people who unblock you, and turn each fix into searchable cohort memory.

Pitch: Cohort SOS turns "I'm stuck" Discord messages into live rescue rooms, helper rewards, and a searchable memory of every fix.

Core User Flow

  1. A builder launches an SOS with category, urgency, time needed, context, and optional repo/live links.
  2. The SOS appears on the live help board with claimed or unclaimed state.
  3. Helpers claim the SOS, join a rescue room, ask questions, and add notes.
  4. The requester resolves the SOS, credits helpers, and writes a final fix note.
  5. Helpers earn Rescue Rep and badges. The fix note becomes searchable knowledge.

Data Model

  id: string;
  name: string;
  githubHandle: string;
  avatarUrl: string;
  skills: string[];
  rescueRep: number;
  badges: string[];
};

type SOS = {
  id: string;
  title: string;
  category: SOSCategory;
  urgency: Urgency;
  status: "open" | "claimed" | "resolved";
  requesterId: string;
  helperIds: string[];
  context: string;
  repoUrl?: string;
  liveUrl?: string;
  timeNeededMinutes: number;
  createdAt: string;
  resolvedAt?: string;
  fixNote?: string;
  comments: Comment[];
  rewards: Reward[];
};

Reward Rules

Reward actual unblocking, not raw activity.

+10 Unblocked me +5 Diagnosed +3 Tested/reviewed +2 Fix note +1 Fast response

Build Order

  1. Create app shell, navigation, seeded users, and seeded SOS requests.
  2. Build Help Board with cards, filters, status, and empty states.
  3. Build Launch SOS with validation and immediate board update.
  4. Build Rescue Room with claim flow, comments, helper list, and resolve button.
  5. Build Resolve Flow with rewards, fix note, Rescue Rep update, and knowledge entry.
  6. Build Leaderboard with badges, recent kudos, and helper categories.
  7. Build Knowledge Base with search and category filters.
  8. Polish demo with realistic seed data, mobile layout, and a crisp Loom sequence.

Demo Script

  1. Explain that Discord is great for chat, but help requests disappear.
  2. Open the dashboard and launch a high-urgency SOS.
  3. Show it appearing on the board and getting claimed by a helper.
  4. Open the rescue room, add a debugging comment, and resolve the SOS.
